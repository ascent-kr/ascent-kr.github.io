1문서 종류는 위에서 한 번만

견적서 · 거래명세서 · 상세 공사내역서가 같은 입력값을 공유합니다. 견적서를 보낸 뒤 거래명세서로 바꿀 때는 저장한 문서에서 거래명세서로 버튼을 누르면 품목이 그대로 넘어갑니다.

2어디에도 전송되지 않습니다

거래처, 계좌번호, 도장 이미지를 포함한 모든 내용은 이 브라우저의 저장 공간(localStorage)에만 남습니다. 서버도, 계정도, 로그인도 없습니다.

3이미지(PNG) 저장

미리보기의 PNG 저장을 누르면 문서 부분만 고해상도로 저장됩니다. 카톡·문자로 바로 보내기 좋습니다. (여러 장이면 세로로 이어 붙입니다.) 아이폰에서는 내려받은 이미지가 파일 앱에 저장되니, 카톡에서 파일로 골라 보내면 됩니다.

4PDF 저장 · 인쇄

PDF·인쇄를 누르고 인쇄 대화상자에서 PDF로 저장을 고르세요. 아이폰 사파리는 공유 → 프린트 → 미리보기에서 파일로 저장하면 PDF가 됩니다. 여백은 없음, 배율 100%로 두세요.

5아이폰 홈 화면에 앱처럼

사파리에서 이 파일을 연 뒤 공유 → 홈 화면에 추가를 누르면 앱처럼 열립니다. 인터넷 없이도 동작합니다. (파일을 옮기거나 브라우저 저장 공간을 지우면 기록도 사라지니, 가끔 전체 백업으로 파일을 받아 두세요.)

6부가세 3가지

부가세 포함 — 입력한 단가·수량이 이미 부가세가 포함된 금액입니다. 총액은 그대로 두고 공급가액과 세액을 나눠 표시합니다.
부가세 별도 — 입력한 금액이 공급가액이고, 10%를 더해 합계를 냅니다.
일반(부가세 없음) — 세액 줄 없이 품목 합계만 표시합니다. 현금 거래·간이과세·부가세 미표기 견적용.

7고객 이메일로 바로 보내기

공급받는자에 이메일을 적어 두고 메일 버튼을 누르면 메일 앱이 열립니다. 제목·본문(합계금액·입금계좌·연락처)이 자동으로 채워집니다. 사업자마다 다른 우리 이메일을 저장해 두었다면 본문에 회신 메일 줄이 함께 들어가 받는 분이 바로 회신할 수 있습니다. 메일로는 파일이 자동 첨부되지 않으니, 먼저 PNG 저장 또는 PDF로 받은 파일을 메일 앱에서 첨부해 발송하세요. 이메일을 비워 두면 받는사람 없이 열려 직접 입력할 수 있습니다.

사업자 정보·도장·계좌·우리 이메일은 사업자별로 저장됩니다. 01 사업자 카드의 사업장 주소·우리 이메일 칸에 바로 적으면 그 사업자에 저장되어 다음 문서에도 자동으로 들어갑니다. 프리셋에 없는 사업자는 + 사업자 추가로 만드세요.
